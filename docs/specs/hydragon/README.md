# HyDragon Integration Notes

These notes describe only the supported Tamework boundary for HyDragon:

- [Capture policy](capture-policy.md)
- [Integration contract](integration-contract.md)

Earlier proposals for population groups, command rosters, timed summoning,
provisioning, paid revival, and companion inventory described unreleased
systems that were removed during persistence consolidation. They are not
supported or reserved API surfaces. Their files were deleted so this directory
cannot be mistaken for an implementation roadmap.
