# Bonded Vessels — Withdrawn Design

Status: Withdrawn before release

The bonded-vessel design is no longer a Tamework or HyDragon requirement. It is replaced by [Command-Roster Capture, Timed Summoning, and Paid Revival](command-roster-capture-revival.md).

The replacement design uses consumable capture attempts, in-place taming, durable command-family rosters, and paid command-panel revival. Implementation must remove the bonded-vessel API, capability, configuration, persistence, runtime, diagnostics, examples, and tests listed in the replacement specification.

HyDragon has never shipped. Do not add item migration, profile adoption, alias IDs, compatibility readers, or another transitional vessel mode.
