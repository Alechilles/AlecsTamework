# Avatar Flight Audio Sources

The sampled avatar-flight launch charge gusts are modified excerpts from
[Harsh Wind by DRAGON-STUDIO](https://pixabay.com/sound-effects/nature-harsh-wind-515272/),
used under the [Pixabay Content License](https://pixabay.com/service/license-summary/).

The original recording is not redistributed in this repository. Download it as
`dragon-studio-harsh-wind-515272.mp3` and pass its path with `--wind-source` when
regenerating the launch audio. The generator defaults to the user's Downloads
folder.

The full-charge ready cue is derived from
`Polished_anime-style_#3-1783957481053.mp3`, an ElevenLabs-generated sound
provided by the project author. The original MP3 is not redistributed in this
repository. Pass its path with `--ready-source` when regenerating the launch
audio; the generator defaults to the user's Downloads folder.

The sampled launch release bursts are modified from
[Gust of Wind by DRAGON-STUDIO](https://pixabay.com/sound-effects/nature-gust-of-wind-511325/),
used under the [Pixabay Content License](https://pixabay.com/service/license-summary/).
The original recording is not redistributed in this repository. Download it as
`dragon-studio-gust-of-wind-511325.mp3` and pass its path with `--release-source`
when regenerating the launch audio. The generator defaults to the user's
Downloads folder.
