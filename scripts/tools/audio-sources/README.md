# Avatar Flight Audio Sources

The sampled avatar-flight launch charge gusts are modified excerpts from
[Harsh Wind by DRAGON-STUDIO](https://pixabay.com/sound-effects/nature-harsh-wind-515272/),
used under the [Pixabay Content License](https://pixabay.com/service/license-summary/).

The original recording is not redistributed in this repository. Download it as
`dragon-studio-harsh-wind-515272.mp3` and pass its path with `--wind-source` when
regenerating the launch audio. The generator defaults to the user's Downloads
folder.
